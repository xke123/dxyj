# 02. 单区域玩法与推理闭环

---

## 一、 核心闭环流程（Five-Step Gameplay Loop）

每一个区域的探索都遵循一个严密的**“信息推理与层级开锁”**闭环：

```
      [ 1. 盲目下挖 ]
             │  掘出地质断层、生活垃圾、古瓦残砖
             ▼
      [ 2. 推理：这里是哪里？ ]
             │  凭借出土物特征锁定旧时代地理/历史坐标
             ▼
      [ 3. 推理：这里有什么宝藏？ ]
             │  结合历史与地域渊源推断深处沉睡的核心重器
             ▼
      [ 4. 寻宝与开锁：宝藏即是钥匙 ]
             │  一层一层发掘层级宝藏，解开通往更深处的古老密锁
             ▼
      [ 5. 发掘大秘宝，点燃人类之光 ]
                冲破冰封，完成该区域文明复苏
```

---

## 二、 阶段细节详解

### 步骤 1：盲目下挖（信息与物证搜集）
* 玩家初抵某处冰原，四周空无一物，只能选定位置向下试探性破冰挖掘。
* 在浅地层（0 ~ 100米）中，玩家不断挖出各种杂乱破碎的遗留物：
  * **地质样本**：含红壤矿物颗粒、盐渍海泥结晶、耐寒黑钙土等。
  * **日常遗物**：烧制陶器残片、特殊刻印的铸币、特定年代的金属标牌等。
  * **建筑碎块**：榫卯木构碳化残件、古代大理石柱雕花、工业铆接槽钢等。

### 步骤 2：推理地点（“这里曾经是哪里？”）
* 盗墓贼打开随身【探勘记事簿】，整理所见物证：
  * *推导示例*：“土质混杂黑黏土与碎陶，瓦片上带着青绿釉色，金属牌有‘京华’印记……这绝不是荒郊野岭，这底下深埋的是当年极富盛名的**文明古都旧址**！”
* 成功判断地点后，地图上的“未知盲区”被正式点亮，确立为具体历史遗迹区域。

### 步骤 3：推理宝藏（“这里深处有什么大秘宝？”）
* 地点一旦锁定，盗墓贼的行业直觉开始发挥作用：
  * *推导示例*：“既然这里曾是一国枢纽、帝王殿堂，地下最深的核心密室里，必然封存着象征天下大统的最高信物——**镇国之印**！”
* 明确了本区域终极“大秘宝”的目标后，深层勘探路径正式激活。

### 步骤 4：寻宝与开锁（“宝藏就是钥匙”）
* 深入地底的道路并非坦途，每一层地宫都由古老而厚重的机关石门、合金密封门所隔断。
* 门上设有特殊的凹槽或机关锁，普通钻具无法破坏。
* **破局关键：每一层挖出的独特“次级宝物”，本质就是下一层大门的“钥匙”**：
  * **浅层宝物（信物钥匙）**：在浅层挖出的青铜符印，正好契合第一道地宫石门的嵌槽；
  * **中层宝物（传动钥匙）**：在中层挖出的特种精密齿轮，补全了第二道沉重千斤闸的动力连杆；
  * **深层宝物（能量钥匙）**：在深层起出的能量辉石，为第三道能量护盾提供了匹配频率。
* 玩家在挖掘与消除过程中，既是在收集宝藏，也是在不断获取通向深渊的通行凭证。

### 步骤 5：发掘大秘宝，点燃人类之光
* 穿过全部锁闭门，到达区域最深处的祭坛/控制中枢。
* 终极挑战：在限定耐力与步数下，通过最精密的大型方块消除连锁，完整起出**【大秘宝】**。
* 大秘宝出土后发生能量共振，一道金光穿透所有挖掘竖井，直刺云霄，点燃本区域的**【人类之光】**。
